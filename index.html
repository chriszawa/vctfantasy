      O ID é o número no link do evento: vlr.gg/event/2501/... Funciona com o site aberto no seu computador e a API ligada.

      Ou cole o JSON da série

      Como pegar

      1. Suba a vlrggapi na sua máquina com uv run python main.py.
      2. Abra no navegador 127.0.0.1:3001/v2/match/details?match_id=ID. O ID é o número do link da série no VLR.
      3. Copie tudo e cole aqui. Repita para cada série da semana.

      Aceita a resposta inteira da API, só o campo data ou uma lista de séries.

      No site online

      No GitHub, abra Actions → Coletar rodada → Run workflow, informe o ID do evento e a semana. Em uns 2 minutos a rodada aparece aqui sozinha.

      Próxima etapa

      Mercado

      Preço inicial

      Sai do overall de cada jogador, calculado com a temporada 2026: 4 + 0,017 × (overall − 60)². Overall 90 custa C$ 19,30.

      Valorização

      Depois de cada rodada: 0,15 × (pontos − preço), com limite de 15% de variação.

      Patrimônio

      C$ 80 para 5 jogadores e 1 coach. Dá para levar uns dois craques e completar o time.

      Próxima etapa

      Cartas

      Atributos

      Mira, Dano, Impacto, Entrada, Suporte, Consistência e Sobrevivência, de 40 a 99 por percentil na liga.

      Overall por função

      Pesos diferentes para duelista, iniciador, controlador e sentinela, como posição no FIFA.

      Manutenção

      Recalculado a cada 3 rodadas misturando 2026 com o ano novo, pelo peso de rounds jogados.
